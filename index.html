01 Create robots.txt public/robots.txt Critical ▼

Likely missing or misconfigured — may be blocking Google's crawler entirely. Place in public/ so Vite serves it at the site root.

robots.txt
User-agent: *
Allow: /

Sitemap: https://www.drkstickers.com/sitemap.xml
💡 Verify after deploy: Visit drkstickers.com/robots.txt in the browser to confirm it's live.
02 Create sitemap.xml public/sitemap.xml Critical ▼

Tells Google about all your pages. Without it, important pages may never get crawled even after indexing is fixed.

xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://www.drkstickers.com/</loc>
    <priority>1.0</priority>
  </url>
  <url>
    <loc>https://www.drkstickers.com/services</loc>
    <priority>0.9</priority>
  </url>
  <url>
    <loc>https://www.drkstickers.com/gallery</loc>
    <priority>0.8</priority>
  </url>
  <url>
    <loc>https://www.drkstickers.com/about</loc>
    <priority>0.7</priority>
  </url>
  <url>
    <loc>https://www.drkstickers.com/contact</loc>
    <priority>0.7</priority>
  </url>
</urlset>
💡 After deploy: Go to Google Search Console → Sitemaps → submit sitemap.xml.

07 Add Internal Links Between Pages src/pages/*.jsx On-Page ▼

Poor internal linking means Google can't efficiently discover your site structure. Every page should link to at least 2 others.

jsx
import { Link } from 'react-router-dom'

// Homepage
<Link to="/services">Explore Our Services →</Link>
<Link to="/gallery">View Our Work</Link>

// Services page
<Link to="/contact">Book This Service</Link>
<Link to="/gallery">See Results in Our Gallery</Link>

// Footer — link to all pages
<Link to="/">Home</Link>
<Link to="/services">Services</Link>
<Link to="/about">About</Link>
<Link to="/contact">Contact</Link>
💡 Always use React Router's <Link>, not <a href>, for internal navigation to avoid full page reloads.
🟢 Content & Structure
08 Create Separate Page Routes + Fix vercel.json App.jsx vercel.json Content ▼

Separate pages let each URL rank independently. Also, React Router requires a Vercel rewrite or direct URL visits will return a 404.

App.jsx
import { BrowserRouter, Routes, Route } from 'react-router-dom'

<BrowserRouter>
  <Routes>
    <Route path="/"         element={<Home />}    />
    <Route path="/services" element={<Services />} />
    <Route path="/gallery"  element={<Gallery />}  />
    <Route path="/about"    element={<About />}    />
    <Route path="/contact"  element={<Contact />}  />
    <Route path="/blog"     element={<Blog />}     />
  </Routes>
</BrowserRouter>
vercel.json
{
  "rewrites": [
    { "source": "/(.*)", "destination": "/index.html" }
  ]
}
💡 Without the vercel.json rewrite, refreshing any route like /services returns a 404. This tells Vercel to serve index.html and let React handle routing.
09 Add FAQ Section to Services Page src/pages/Services.jsx Content ▼

FAQs improve dwell time, naturally include long-tail keywords, and can appear as rich snippets in Google search.

Services.jsx
import { useState } from 'react'

const faqs = [
  { q: "How long does a car wrap last?",
    a: "A quality vinyl wrap lasts 5–7 years with proper care." },
  { q: "Do you offer ceramic coating in Chennai?",
    a: "Yes, at our Chennai facility." },
  { q: "What types of vehicles can be wrapped?",
    a: "Cars, SUVs, bikes, trucks and commercial vehicles." },
  { q: "How much does a full car wrap cost?",
    a: "Depends on size and wrap type. Contact us for a free quote." },
]

export function FAQ() {
  const [open, setOpen] = useState(null)
  return (
    <section>
      <h2>Frequently Asked Questions</h2>
      {faqs.map((f, i) => (
        <div key={i} onClick={() => setOpen(open === i ? null : i)}>
          <h3>{f.q}</h3>
          {open === i && <p>{f.a}</p>}
        </div>
      ))}
    </section>
  )
}
💡 Use keywords naturally in the question and answer text. Add FAQPage JSON-LD schema to enable rich snippets in Google.

🚗 DRK Stickers - SEO Implementation Checklist

Complete Guide to SEO Setup & Optimization

🔴 Critical Tasks (Do These First)

PRIORITY 1
Task 1 — Fix robots.txt
File: public/robots.txt
Create this file if it doesn't exist:
User-agent: *
Allow: /

Sitemap: https://www.drkstickers.com/sitemap.xml
⚠️ Anything in /public gets served at root. So public/robots.txt → drkstickers.com/robots.txt
Task 2 — Generate & Submit Sitemap
File: public/sitemap.xml
Create XML sitemap with all your pages:
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/0.9">
<url><loc>https://www.drkstickers.com/</loc></url>
<url><loc>https://www.drkstickers.com/services</loc></url>
<url><loc>https://www.drkstickers.com/gallery</loc></url>
<url><loc>https://www.drkstickers.com/about</loc></url>
<url><loc>https://www.drkstickers.com/contact</loc></url>
</urlset>
⚠️ After deploying, go to Google Search Console → Sitemaps → paste the URL → Submit
Task 3 — Add Meta Titles & Descriptions
File: Use react-helmet-async for per-page meta
Install the package:
npm install react-helmet-async
Wrap app in main.jsx:
import { HelmetProvider } from 'react-helmet-async'

<HelmetProvider>
  <App />
</HelmetProvider>
Use in each page component:
import { Helmet } from 'react-helmet-async'

<Helmet>
  <title>Custom Car Wraps & Stickers in Chennai | DRK Stickers</title>
  <meta name="description" content="..." />
</Helmet>
⚠️ Each page needs a unique title and description. Include the city name and main keyword.
Task 4 — Add Google Analytics (GA4)
File: index.html inside <head>
<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-XXXXXXXXXX');
</script>
⚠️ Replace G-XXXXXXXXXX with the real ID from analytics.google.com → Admin → Data Streams

🟠 On-Page SEO Tasks

PRIORITY 2
Task 5 — Fix All Image Alt Text
Find every <img> tag in src/ and update with descriptive alt text:
❌ Bad:
<img src="/car-wrap.jpg" />

✅ Good:
<img src="/car-wrap.jpg" alt="custom vinyl car wrap service Chennai" />
⚠️ Search for <img across all files in src/. Every image needs a descriptive alt tag with a keyword.
Task 6 — Add Schema Markup (JSON-LD)
File: index.html inside <head>
Add this structured data:
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "LocalBusiness",
  "name": "DRK Stickers",
  "url": "https://www.drkstickers.com",
  "telephone": "+91-XXXXXXXXXX",
  "address": {
    "@type": "PostalAddress",
    "streetAddress": "Your Street",
    "addressLocality": "Chennai",
    "postalCode": "XXXXXX",
    "addressCountry": "IN"
  },
  "description": "Premium car wraps, vinyl stickers...",
  "openingHours": "Mo-Sa 09:00-19:00"
}
</script>
⚠️ Fill in real address and phone. Test at: schema.org/docs/validator
Task 7 — Add Internal Links Between Pages
Link pages to each other for better navigation:
<Link to="/services">Explore Our Services →</Link>
<Link to="/contact">Book a Service</Link>
<Link to="/gallery">View Our Work</Link>
⚠️ Every page should link to at least 2 other pages. Never leave a page as a dead end.

🟡 Content & Page Structure Tasks

PRIORITY 3
Task 8 — Create Separate Route Pages
Organize your pages in the src/pages/ folder:
src/
  pages/
    Home.jsx
    Services.jsx
    Gallery.jsx
    About.jsx
    Contact.jsx
    Blog.jsx
    BlogPost.jsx
Update your router in App.jsx:
<Routes>
  <Route path="/" element={<Home />} />
  <Route path="/services" element={<Services />} />
  <Route path="/gallery" element={<Gallery />} />
  <Route path="/about" element={<About />} />
  <Route path="/contact" element={<Contact />} />
</Routes>
⚠️ Make sure vercel.json handles client-side routing correctly.
Task 9 — Add FAQ Section
Add FAQs to your Services page:
const faqs = [
  { q: "How long does a car wrap last?", a: "5–7 years with proper care." },
  { q: "Do you offer ceramic coating?", a: "Yes, professional coating services." }
]
⚠️ Use keywords naturally in both questions and answers.
Task 10 — Add Location Keywords to Pages
Update your copy with local SEO keywords:
✅ Good:
<h1>Premium Car Wraps & Stickers in Chennai</h1>
<p>Serving customers across Chennai, Tambaram...</p>
⚠️ Include city names and local areas in headings and content.

1
Install the package

Install react-helmet-async. This is safer than the original react-helmet (which has a known memory leak in SSR).

Terminal
# npm
npm install react-helmet-async

# or yarn
yarn add react-helmet-async

# or pnpm
pnpm add react-helmet-async
Why react-helmet-async? It uses React Context properly and is safe for server-side rendering — important if you plan to add SSR later.

3
Wrap your app in HelmetProvider

Open src/index.jsx (or main.jsx) and wrap the entire app. This is done once only.

src/index.jsx
import React from 'react'
import ReactDOM from 'react-dom/client'
import { HelmetProvider } from 'react-helmet-async'  // ← import this
import App from './App'
import './index.css'

ReactDOM.createRoot(document.getElementById('root')).render(
  <React.StrictMode>
    <HelmetProvider>   {/* ← wrap here */}
      <App />
    </HelmetProvider>
  </React.StrictMode>
)
Done once. Every <Helmet> tag anywhere inside the app will now work correctly.

4
Create the reusable SEO component

Create src/components/SEO.jsx. This is your single place for all meta tag logic — every page just passes its own values as props.

src/components/SEO.jsx
import { Helmet } from 'react-helmet-async'

export default function SEO({
  title,
  description,
  keywords,
  canonical,
  ogImage = 'https://drkstickers.com/images/default-og.jpg',
  ogType = 'website',
}) {
  const siteName = 'DRK Stickers Coimbatore'
  const fullTitle = `${title} | ${siteName}`

  return (
    <Helmet>
      {/* Basic */}
      <title>{fullTitle}</title>
      <meta name="description" content={description} />
      <meta name="keywords" content={keywords} />
      <link rel="canonical" href={canonical} />

      {/* Open Graph (Facebook, WhatsApp, LinkedIn) */}
      <meta property="og:type" content={ogType} />
      <meta property="og:site_name" content={siteName} />
      <meta property="og:title" content={fullTitle} />
      <meta property="og:description" content={description} />
      <meta property="og:url" content={canonical} />
      <meta property="og:image" content={ogImage} />
      <meta property="og:image:width" content="1200" />
      <meta property="og:image:height" content="630" />

      {/* Twitter / X */}
      <meta name="twitter:card" content="summary_large_image" />
      <meta name="twitter:title" content={fullTitle} />
      <meta name="twitter:description" content={description} />
      <meta name="twitter:image" content={ogImage} />
    </Helmet>
  )
}
Tip: The fullTitle auto-appends your site name so you only pass short titles like "Car Detailing Services" and it becomes "Car Detailing Services | DRK Stickers Coimbatore".

6
Set up React Router (App.jsx)

Your App.jsx handles routing. Make sure each route renders its page component (which already includes the SEO component inside it).

src/App.jsx
import { BrowserRouter, Routes, Route } from 'react-router-dom'
import Home from './pages/Home'
import Services from './pages/Services'
import SunFilm from './pages/SunFilm'
import Ceramic from './pages/Ceramic'
import Contact from './pages/Contact'

export default function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/services" element={<Services />} />
        <Route path="/sun-film" element={<SunFilm />} />
        <Route path="/ceramic-coating" element={<Ceramic />} />
        <Route path="/contact" element={<Contact />} />
      </Routes>
    </BrowserRouter>
  )
}
How it works: When the URL changes to /sun-film, React renders <SunFilm /> which contains its own <SEO> — so the meta tags update automatically on every navigation.

7
Fix for Google — add prerendering (SSR)

react-helmet-async updates tags in the browser, but Google's crawler reads the raw HTML before JavaScript runs. You need one of these solutions:

⚠️ Without this step, Inspect Element will show correct tags but View Page Source will still show homepage tags — and Google will still not read them.
Option A — Migrate to Next.js (Best long-term fix)
# Create a new Next.js project
npx create-next-app@latest drk-stickers-next

# Copy your React components into the new project
# Replace react-helmet-async with next/head or generateMetadata()
# No other changes needed to your page logic
Option B — Add Vite SSR plugin (if using Vite)
npm install vite-plugin-ssr

# This adds server-side rendering to your existing
# Vite + React project without a full migration
Option C — Use a prerender service (quickest fix)
# Services like prerender.io or Netlify Edge Functions
# intercept bot requests and serve a pre-rendered HTML snapshot
# Your React app stays unchanged — just add the service in front of it

# Popular options:
# - prerender.io (paid, plug-and-play)
# - Netlify Edge Functions (free tier available)
# - Vercel (deploy your app there, SSR is automatic)
Quickest win: Deploy to Vercel. Connect your GitHub repo, Vercel automatically detects React and handles prerendering. Free for small sites.

8
Test that it's working

After implementing, verify each page has unique meta tags:

Browser test
1. Go to https://drkstickers.com/sun-film
2. Right-click → View Page Source
3. Press Ctrl+F and search: og:title
4. You should see: "Sun Film Installation Coimbatore | DRK Stickers"
   NOT: "Best Car Detailing & Sun Film Studio | DRK Stickers"

If it shows homepage title → SSR is not active yet (Step 7 needed)
If it shows the right title → ✅ Done!

Each page URL shows a different title in View Page Source
Each page has a unique description and canonical URL
og:url matches the actual page URL (not the homepage)
Google Search Console shows no "Duplicate title tags" warnings
